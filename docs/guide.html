직접 배포하기

공용으로 배포된 인스턴스 대신, 본인 소유의 Render + Upstash Redis로 나만의 인스턴스를 띄우고 싶다면 이 가이드를 따라하세요. 전체 세부 설정(콘솔 스크린샷 수준)은 저장소 README가 더 자세하니, 막히는 단계가 있으면 그쪽을 참고하세요.

💡 자기 계정으로 카카오/Notion 콘솔에서 앱을 새로 만들어야 하는 이유: 이 프로젝트는 OAuth 기반이라, 앱 소유자(배포하는 사람)가 카카오/Notion 개발자 콘솔에서 본인 명의의 OAuth 앱을 한 번만 만들면, 그 뒤로 모든 사용자는 "연결" 버튼만 누르면 됩니다.

1. 저장소 준비

  1. GitHub에서 저장소를 Fork (또는 그대로 clone해서 본인 저장소로 push)
  2. 로컬에서 실행해보려면:
git clone <fork한 저장소 URL>
cd notion-kakao-schedule
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

2. 환경변수

아래 값들은 전부 각 플랫폼 개발자 콘솔에서 본인 명의로 직접 발급받아야 합니다 (자세한 발급 절차는 README의 "카카오 개발자 앱 설정" / "Notion 연동 설정" / "Google Calendar 연동 설정" 절 참고).

변수용도
REDIS_URLUpstash Redis 연결 문자열
SESSION_SECRET_KEY세션 쿠키 서명용 랜덤 문자열
KAKAO_REST_API_KEY카카오 로그인 + 메시지 전송용 앱 키
KAKAO_CLIENT_SECRET(선택) 같은 카카오 앱의 Client Secret
NOTION_CLIENT_ID / NOTION_CLIENT_SECRETNotion OAuth 공개 통합
GOOGLE_CLIENT_ID / GOOGLE_CLIENT_SECRETGoogle Calendar 연동용 (선택)
CRON_SECRETGitHub Actions 백업 트리거 인증 (배포 시에만 필요)

3. Render 배포

  1. Render → New → Web Service → Fork한 저장소 연결
  2. Build Command: pip install -r requirements.txt
  3. Start Command: uvicorn app.main:app --host 0.0.0.0 --port $PORT
  4. Environment Variables에 위 표의 항목을 전부 추가
  5. Deploy
⚠️ 순서 주의: 환경변수를 먼저 추가한 뒤 코드를 push하세요. 반대 순서면 env var가 없어서 해당 라우트가 500 에러를 냅니다.

4. Upstash Redis (무료)

Render 무료 웹서비스는 디스크가 재배포마다 초기화되므로, 설정을 유지하려면 외부 저장소가 필요합니다. upstash.com에서 Redis 데이터베이스를 무료로 만들고, TCP 연결 URL을 REDIS_URL에 넣으세요.

5. (선택) 항상 깨어있게 유지하기

Render 무료 플랜은 일정 시간 요청이 없으면 서버가 잠드는데, 그러면 내부 스케줄러도 같이 멈춥니다. UptimeRobot 같은 무료 핑 서비스로 5분마다 /settings를 호출해서 깨어있게 유지하세요.

6. (선택) 발송 실패 백업 트리거

내부 스케줄러가 발송에 실패해도 알 수 있도록, GitHub Actions가 10분 뒤 /internal/run-daily를 호출해 재시도하고 실패 시 이메일로 알려주는 안전망이 포함돼 있습니다(.github/workflows/daily-notify-backup.yml). 저장소 Settings → Secrets에 CRON_SECRET, Variables에 APP_URL만 추가하면 자동으로 동작합니다.

전체 설정(카카오/Notion/Google 콘솔 화면별 절차, 트러블슈팅)은 저장소 README에 가장 자세히 정리돼 있습니다.
