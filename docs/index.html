오늘 일정, 아침마다
카카오톡으로 받아보세요

Notion(+ 선택적으로 Google Calendar)에서 오늘 날짜의 일정을 가져와, 매일 지정한 시각에 카카오톡 "나에게 보내기"로 요약해서 보내드립니다.

카카오로 시작하기 ⭐ GitHub에서 보기

무료 · 회원가입 없이 카카오 로그인만으로 시작

기능

🔗

원클릭 OAuth 연동

Notion / 카카오 / Google Calendar 전부 OAuth 연결이라, API 키나 토큰을 직접 복사-붙여넣기할 필요가 없어요.

⏰

매일 자동 발송

알림 받을 시각을 한 번 설정하면, 그 이후로는 매일 아침 자동으로 오늘 일정을 보내드려요.

📊

발송 이력 대시보드

성공/실패 이력과 성공률을 대시보드에서 바로 확인할 수 있고, 실패 시 백업 트리거가 자동으로 재시도합니다.

🌗

다크모드 지원

설정 페이지와 대시보드 모두 시스템 설정을 자동 감지하는 다크모드를 지원합니다.

사용법

1

카카오로 로그인

로그인 한 번으로 신원 확인과 메시지 발송 동의가 동시에 끝나요.

2

Notion 연결

"Notion 연결" 버튼을 누르고 캘린더 뷰 데이터베이스를 고르면, 날짜/제목 속성은 자동으로 감지돼요.

3

알림 시각 설정

원하는 시각을 저장하면 끝. 그 시각에 맞춰 매일 카카오톡으로 오늘 일정이 도착합니다.

이 프로젝트는 오픈소스입니다. 소스코드를 직접 확인하거나, 포크해서 나만의 인스턴스로 배포할 수도 있어요.
