# check-send-status 스킬

Redis에 저장된 발송 이력을 조회하고 현재 상태를 한눈에 파악합니다.

## 조회 항목

1. **마지막 발송 상태**
   - 발송 시각
   - 성공/실패 여부

2. **최근 5개 이력**
   - 발송 시각
   - 상태 (✅/❌)
   - 출처 (자동/백업/수동)
   - 에러 메시지 (있을 경우)

3. **통계**
   - 전체 발송 횟수
   - 성공 횟수
   - 성공률 (%)

## 실행

```bash
check-send-status
```

## 결과 예시

```
📊 발송 상태 조회

📌 마지막 발송 상태:
  시간: 2026-09-08 08:00:15
  상태: success ✅

📜 발송 이력 (최근 5개):
  1. [09-08 08:00] ✅ 자동
  2. [09-07 08:00] ✅ 자동
  3. [09-06 14:30] ✅ 수동
  4. [09-05 08:00] ✅ 자동
  5. [09-04 08:00] ✅ 자동

📈 통계:
  전체: 142개 | 성공: 140개 | 성공률: 98.6%

✨ 조회 완료!
```

## 환경변수

`REDIS_URL` 환경변수가 필요합니다. Render 배포 환경에서 자동 로드됩니다.

로컬에서 테스트할 경우:
```bash
export REDIS_URL="<Render에서 복사한 URL>"
check-send-status
```
